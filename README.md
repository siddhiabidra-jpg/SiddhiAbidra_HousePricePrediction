# House Price Prediction System

## Project Overview
This project is a Machine Learning-powered web application designed to predict residential house prices based on critical features such as total area, number of bedrooms, bathrooms, and property age. It translates historical real estate data into actionable business and consumer intelligence.

## Technologies Used
* **Python** (Backend Logic)
* **Scikit-Learn** (Machine Learning Model - Linear Regression)
* **Streamlit** (Interactive Frontend UI)
* **Pandas & NumPy** (Data Manipulation)

## Dataset Link
* **Dataset Source:** [Kaggle House Price Dataset](https://www.kaggle.com/)

## Setup and Run Instructions
1. Clone the repository or download the project files.
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application using Streamlit:
   ```bash
   streamlit run SiddhiAbidra_HousePricePrediction.py
   ```
